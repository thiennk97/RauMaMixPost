# RauMaMixPOS

Web POS bán hàng, in tem 40×30mm (ITP3300 qua Android APK Bridge / WebUSB / Chrome) và xem doanh thu cho Rau Má Mix.

- `frontend/`: Vue 3 + Vite
- `backend/`: Node.js + Express (`db.json`)
- `google-sheet/`: `Code.gs` (Google Apps Script làm Backend + DB trên Google Sheets)
- `android-bridge/`: Android APK Bridge (`127.0.0.1:9191` → USB ITP3300)
